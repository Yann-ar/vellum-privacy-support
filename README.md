# vellum-privacy-support

Official privacy policy and support website for Vellum.

- Privacy policy: `/privacy/`
- Support: `/support/`
- Languages: Simplified Chinese, English, Japanese, and Korean
- Current policy effective date: July 30, 2026
- No analytics, advertising trackers, cookies, or external fonts

The deployed HTML is generated from the same four-language legal catalog used by the Vellum iOS app.
